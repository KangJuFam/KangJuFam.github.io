mac (Minecraft Auto Channel) — 유튜브 채널 강주놀이터가 쓰는 API 클라이언트
시행일 2026-08-29

이 소프트웨어는 공개 배포되지 않습니다. 소유자 본인만 자신의 PC에서 사용하며, 제3자에게 제공·판매·라이선스하지 않습니다. 따라서 이 약관의 적용 대상은 소유자 본인 한 명입니다.

1. 적용 범위

이 약관은 소프트웨어 mac (Minecraft Auto Channel)(이하 "도구")의 사용에 적용됩니다. 도구는 유튜브 채널 강주놀이터의 소유자가 자신이 제작한 영상을 자신의 채널에 올리기 위해 만든 개인용 소프트웨어입니다.

2. 이용 자격

도구는 소유자 본인만 사용합니다. 회원가입, 계정 생성, 사용자 등록 절차가 없으며, 제3자에게 접근 권한을 부여하지 않습니다. 배포용 실행 파일이나 설치 페이지를 제공하지 않고, 소스 코드는 비공개 저장소에 있습니다.

3. 허용되는 사용

  • 소유자가 직접 제작한 영상을 소유자 본인의 채널에 업로드
  • 업로드한 영상에 자체 생성한 썸네일 적용
  • 업로드한 영상을 소유자 본인 소유의 재생목록에 추가
  • 업로드 대상 채널이 맞는지 확인

4. 금지되는 사용

  • 제3자를 대신한 업로드 또는 채널 관리
  • 타인이 제작한 콘텐츠의 재업로드 또는 재배포
  • YouTube API 응답의 저장·캐시·재배포 또는 제3자 제공
  • YouTube 데이터를 YouTube 외부에 노출하는 행위
  • 도구의 판매, 재라이선스, 서비스 형태의 제공

5. YouTube API 서비스

이 도구는 YouTube API 서비스를 사용합니다. 도구를 사용함으로써 사용자는 아래에 동의하는 것으로 간주됩니다.

  • YouTube 서비스 약관
  • Google 개인정보처리방침

도구가 요청하는 OAuth 범위와 데이터 처리 방식은 개인정보처리방침에 적혀 있습니다.

6. 콘텐츠에 대한 책임

도구로 업로드되는 모든 콘텐츠는 소유자가 직접 제작한 것이며, 그에 대한 책임은 소유자에게 있습니다. 업로드는 항상 비공개 상태로 이루어지고, 공개 전환은 사람이 YouTube Studio에서 직접 검토한 뒤 수행합니다.

7. 보증의 부인

도구는 "있는 그대로" 제공됩니다. 개인이 자신의 용도로 만든 소프트웨어이므로 상품성, 특정 목적 적합성, 무중단 동작에 대한 어떠한 보증도 하지 않습니다.

8. 이용 중단

YouTube 또는 Google은 도구가 정책을 준수하지 않을 경우 API 접근을 정지하거나 해지할 수 있습니다. 소유자는 언제든 로컬 토큰 파일을 삭제하고 Google 계정 권한 페이지에서 접근 권한을 철회하여 도구의 사용을 중단할 수 있습니다.

9. 변경

이 약관이 바뀌면 이 페이지를 갱신하고 상단의 시행일을 고칩니다. 도구의 용도가 바뀌는 경우 YouTube에 서면으로 통지합니다.
