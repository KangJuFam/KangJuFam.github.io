mac (Minecraft Auto Channel)

유튜브 채널 강주놀이터에 올릴 마인크래프트 건축 영상을 만들고 업로드하는 1인용 로컬 도구입니다.

이 애플리케이션은 YouTube API 서비스를 사용합니다. 사용에는 YouTube 서비스 약관과 Google 개인정보처리방침이 적용됩니다. 이 애플리케이션의 개인정보처리방침 · 서비스 약관

이 도구는 공개 배포되지 않습니다. 소스는 비공개 저장소에 있고, 실행 파일이나 설치 페이지를 제공하지 않으며, 소유자 본인의 PC에서만 실행됩니다. 사용자는 한 명입니다. 이 페이지는 YouTube API 규정 준수 감사를 위해 도구의 동작을 설명하려고 만들었습니다.

무엇을 하는가

마인크래프트 베드락 에디션에서 직접 지은 건축물을 화면 녹화하고, 편집과 썸네일 생성을 거쳐 소유자 본인의 채널에 올립니다. 영상의 모든 시청각 요소가 자체 제작물입니다.

  1. 건축물 도면을 생성하고 게임 안에서 시공합니다
  2. OBS Studio로 게임 화면을 녹화합니다
  3. 구간을 나누고 재료·치수 안내를 얹어 한 편으로 편집합니다
  4. 썸네일을 만듭니다
  5. 비공개 상태로 업로드하고 재생목록에 넣습니다
  6. 사람이 확인한 뒤 YouTube Studio에서 직접 공개로 바꿉니다

YouTube API 사용 내역

엔드포인트용도범위
channels.list업로드 대상 채널 확인youtube.readonly
videos.insert완성본 업로드 (항상 비공개)youtube.upload
thumbnails.set자체 생성 썸네일 적용youtube.upload
playlistItems.insert본인 소유 재생목록에 추가youtube

요청 범위는 youtube.upload, youtube.readonly, youtube 셋뿐입니다. 하루 사용량은 영상 한 편당 약 1,700 유닛이며 주 1~2편을 발행합니다.

사람이 개입하는 지점

전 과정이 무인으로 돌아가지 않습니다.

  • 업로드는 항상 비공개입니다. 코드에 공개로 자동 전환하는 경로가 없습니다
  • 공개 전환은 사람이 YouTube Studio에서 직접 합니다
  • 업로드 직전에 제목·설명·태그를 모두 출력하고 사람의 확인을 받습니다
  • 게임 안의 시공 명령도 사람이 직접 입력합니다
  • 배경음악 선택도 사람이 합니다

콘텐츠 출처

  • 영상 — 마인크래프트 베드락 에디션 플레이 화면을 OBS Studio로 직접 녹화
  • 건축물 — 자체 개발한 생성기의 도면을 게임 안에서 직접 시공
  • 오버레이·썸네일 — 자체 생성
  • 음악 — YouTube 오디오 보관함의 "저작자 표시 필요 없음" 트랙만 사용

제3자의 영상·음원·이미지를 사용하지 않으며, 다른 채널의 콘텐츠를 재업로드하지 않습니다.

수익

이 API 클라이언트 자체는 수익을 창출하지 않습니다. 도구를 판매·배포하거나 제3자에게 제공하지 않고, 유료 서비스나 구독이 없으며, API 데이터를 제3자에게 판매하거나 공유하지 않습니다.

채널은 현재 수익 창출을 하고 있지 않습니다. 향후 YouTube 파트너 프로그램 자격을 충족하면 가입을 신청할 수 있으며, 그 경우 수익은 YouTube가 운영하는 광고 수익 배분에 한정됩니다.

In English

mac (Minecraft Auto Channel) is a single-user local tool that produces and uploads Minecraft building videos to the owner's own YouTube channel, 강주놀이터 (@kangjuplay).

This tool is not publicly distributed. The source lives in a private repository, no binaries or install page are offered, and it runs only on the owner's own PC. There is exactly one user. This page exists to describe the client for the YouTube API compliance audit.

What it does

The owner builds structures in Minecraft Bedrock Edition, records the gameplay with OBS Studio, and the tool edits the footage, generates a thumbnail, and uploads the finished video to the owner's own channel. Every audiovisual element is original work created by the owner.

YouTube API usage

EndpointPurposeScope
channels.listConfirm the upload target channelyoutube.readonly
videos.insertUpload the finished video (always private)youtube.upload
thumbnails.setApply a self-generated thumbnailyoutube.upload
playlistItems.insertAdd the video to the owner's own playlistyoutube

Human review

  • Uploads are always private. There is no code path that publishes a video publicly
  • Making a video public is done by a person in YouTube Studio
  • Before uploading, the tool prints the full title, description and tags and waits for the operator to confirm
  • The in-game build commands are entered by a person

Content sourcing

All content is original. Gameplay is recorded directly with OBS Studio, the structures are built in-game from our own generator's blueprints, and overlays and thumbnails are generated by our own code. Music comes only from the YouTube Audio Library, limited to tracks marked "no attribution required". We do not use third-party video, audio or images, and we do not re-upload content from other channels.

Revenue

The API client itself does not generate revenue. It is not sold, distributed or made available to third parties, there is no paid service or subscription, and we do not sell or share API data with anyone. The channel is not currently monetized; if it later meets the YouTube Partner Program requirements we may apply, in which case the only revenue would be YouTube's own ad revenue sharing.

Privacy

We do not collect user data. See the Privacy Policy and the Terms of Service.
