이 도구는 사용자의 개인정보를 수집·저장·전송·판매하지 않습니다. 소유자 본인의 PC에서만 실행되는 1인용 도구이며, 소유자 외의 사용자가 존재하지 않습니다.

1. 수집하는 정보

없습니다. 이 도구는 회원가입, 로그인 계정 생성, 사용자 등록 절차가 없습니다. 이름·이메일·전화번호·결제 정보 등 어떤 개인 식별 정보도 수집하지 않습니다. 분석 도구, 쿠키, 광고 추적기를 사용하지 않습니다.

2. Google 계정 접근

소유자가 자신의 YouTube 채널에 영상을 올리기 위해, 도구는 Google OAuth 2.0으로 소유자 본인의 계정 접근 권한을 받습니다. 요청하는 범위는 다음뿐입니다.

  • https://www.googleapis.com/auth/youtube.upload — 영상 업로드와 썸네일 설정
  • https://www.googleapis.com/auth/youtube.readonly — 업로드 대상 채널 확인
  • https://www.googleapis.com/auth/youtube — 소유자 본인의 재생목록에 영상 추가

이 접근은 소유자 본인의 계정에만 적용됩니다. 다른 사용자의 Google 계정에 접근하지 않으며, 접근을 요청할 수단 자체가 없습니다.

3. 인증 토큰의 보관

  • OAuth 토큰은 소유자 PC의 로컬 파일에만 저장됩니다
  • 토큰을 외부 서버로 전송하지 않습니다. 이 도구에는 서버·데이터베이스·백엔드가 없습니다
  • 토큰은 버전 관리(소스 저장소)에서 제외되어 있어 배포·공유되지 않습니다
  • 소유자는 언제든 로컬 토큰 파일을 삭제하고 Google 계정 권한 페이지에서 접근 권한을 철회할 수 있습니다

4. 데이터 전송

이 도구가 발생시키는 네트워크 통신은 YouTube Data API 호출뿐입니다. 영상 파일, 썸네일, 제목·설명·태그가 소유자 본인의 채널로 전송됩니다. 그 외 어떤 목적지로도 데이터를 보내지 않습니다.

5. 제3자 제공

없습니다. 어떤 데이터도 제3자, 광고주, 데이터 브로커에게 제공하거나 판매하지 않습니다. API 응답을 저장·캐시하거나 재배포하지 않습니다.

6. 아동의 개인정보

이 도구는 일반 대중을 위한 서비스가 아니며 소유자 본인만 사용합니다. 아동을 포함한 어떤 사용자로부터도 정보를 수집하지 않습니다.

이 도구는 YouTube API 서비스를 사용합니다. 사용에는 YouTube 서비스 약관과 Google 개인정보처리방침이 적용됩니다.

Privacy Policy (English)

mac (Minecraft Auto Channel) · Effective 2026-08-29

This tool does not collect, store, transmit or sell any user data. It is a single-user tool that runs only on the owner's own PC, and no users other than the owner exist.

1. Information we collect

None. There is no sign-up, no account creation and no user registration. We collect no names, email addresses, phone numbers or payment details. We use no analytics, cookies or advertising trackers.

2. Google account access

So the owner can upload videos to their own YouTube channel, the tool requests access to the owner's own Google account via OAuth 2.0. The only scopes requested are:

  • https://www.googleapis.com/auth/youtube.upload — upload videos and set thumbnails
  • https://www.googleapis.com/auth/youtube.readonly — confirm the upload target channel
  • https://www.googleapis.com/auth/youtube — add videos to the owner's own playlist

This access applies only to the owner's own account. We do not access, and have no mechanism to request access to, any other person's Google account.

3. Storage of authorization tokens

  • The OAuth token is stored only in a local file on the owner's PC
  • It is never transmitted to any external server. The tool has no server, database or backend
  • It is excluded from version control, so it is never distributed or shared
  • The owner can delete the local token file at any time and revoke access at Google Account permissions

4. Data transmission

The only network traffic the tool generates is calls to the YouTube Data API. Video files, thumbnails, titles, descriptions and tags are sent to the owner's own channel. No data is sent anywhere else.

5. Sharing with third parties

None. We do not provide or sell any data to third parties, advertisers or data brokers. We do not store, cache or redistribute API responses.

6. Children's privacy

This tool is not a service for the general public and is used solely by the owner. We collect no information from any user, including children.

7. YouTube Terms of Service

This tool uses YouTube API Services. Use is subject to the YouTube Terms of Service and the Google Privacy Policy.

8. Changes

If this policy changes we will update this page and revise the effective date above.
